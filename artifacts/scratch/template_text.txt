[Body Text 2] This template is intended to assist students in writing their FYP reports, by referring to the report structure for BAXI program. You should change accordingly to your program as stated in the guidelines. Any changes of the structure can still be made depending on your supervisor's consent.
[Body Text 2] Students are advised not to change any of the templates formatting and style since this template was built based on the FYP writing guide.
[Body Text 2] For the body of the text, students must use “Body Text 2” style in the “Styles” window under Home tab.
[Heading 2] About Chapters and First Subtitle
[Body Text 2] For each chapter, type in the name of the chapter (e.g. Introduction) and apply “Heading 1” style.  The style will automatically add numbering starting with ‘Chapter’ in front of the numbering.
[Body Text 2] Create three empty lines before each chapter name.  After each chapter name, leave four empty lines for the new paragraph.  Use “Body Text” style for the empty lines before and after the chapter names only.  For the rest of the normal paragraph, use “Body Text 2” style, as indicated earlier.  For next or new chapter, student must start on a new page.
[Body Text 2] For the first subtopic in each chapter, student can use Heading 2 style for the title.  Do not leave any empty line before starting a new subtitle.
[Heading 3] Second Subtitles
[Body Text 2] For the second subtopic of each chapter, students can choose “Heading 3” style accordingly.  Do not leave any empty line before starting a new subtitle.
[Heading 4] Third Subtitles
[Body Text 2] For the second subtopic of each chapter, students can choose “Heading 4” style accordingly.  Do not leave any empty line before starting a new subtitle.
[Heading 5] Other Subtitles
[Body Text 2] For other subtopics in each chapter use “Heading 5” style for title, with numbering (a), (b), and so on.
